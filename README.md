# App Development 2026 — Homework 2

This project contains the Kotlin lecture exercises, their reference solutions,
and **Homework 2: Modeling a Shop**.

## Getting started

1. Clone your personal assignment repository created by Classmoji.
2. Open the repository in Android Studio.
3. Open `src/main/kotlin/homework/Homework2.kt`.

The complete homework tasks and requirements are in `Homework2.kt`.
Implement the shop model in the `homework` package, splitting the implementation
across multiple files as required. Use the `main` function in `Homework2.kt` to
run the example scenario from the assignment.

## Reference material

- `src/main/kotlin/lecture/`: lecture exercises.
- `src/main/kotlin/lecture/solution/`: solutions to those exercises.
